TRestServer.php : 26

TRestServer — despachante JSON-RPC simples (service + method).

Regista serviços (nome => handler) e atende pedidos onde 'service' e 'method' vêm da query ou do corpo JSON. O método do handler recebe um vetor de parâmetros e o seu retorno é serializado para JSON. Em caso de erro (serviço/método inexistente, exceção) devolve {"error": "..."}.

$server = new TRestServer; $server->addService('Cliente', new ClienteService); echo $server->handle(); // ?service=Cliente&method=onList
