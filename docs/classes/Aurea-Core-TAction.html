TAction.php : 22

TAction — encapsula um evento (controller + método + parâmetros).

Um evento é disparado via URL do Front Controller: index.php?class=ClienteList&method=onReload&limit=10

Pode ser serializada para href ou onclick (navegação ou AJAX).

Uso: new TAction(['ClienteList', 'onReload'], ['order' => 'nome']); new TAction([ClienteForm::class, 'onEdit'], ['key' => 1]);
