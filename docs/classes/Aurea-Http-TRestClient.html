TRestClient — cliente REST mínimo sobre stream context (sem ext-curl).

Envia e recebe JSON; cada chamada devolve ['status' => int, 'data' => mixed]. Falhas de transporte (ex.: serviço inalcançável) devolvem status 0 e data null em vez de lançar exceção, para o chamador decidir.
