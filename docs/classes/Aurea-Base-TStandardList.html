TStandardList — página de listagem a partir do StandardListTrait.

A subclasse declara a base de dados, o Active Record, os campos de filtro e a montagem do filtro e da grid; onReload/onDelete/onExportCSV são genéricos. As propriedades $database/$activeRecord/$filterFields do trait são preenchidas no construtor a partir dos métodos abstratos.
