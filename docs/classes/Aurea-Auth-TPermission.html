TPermission.php : 22

TPermission — autorização por programa (whitelist de acessos).

Modelo aberto: sem nenhuma regra registada, check() permite tudo. Assim que existir pelo menos uma concessão, só programas concedidos (globalmente ou ao utilizador) são permitidos.

TPermission::grant('ClienteList'); // global (todos) TPermission::grant('Admin', '1'); // só utilizador 1 TPermission::setChecker(fn($p, $u) => ...); // regra externa (precedência) TMenu::fromXml($file, TPermission::menuFilter());
